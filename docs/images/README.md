# Capturas de evidencia

Esta carpeta guarda las capturas referenciadas por el README y por los archivos
de `evidence/`. Antes de agregar una imagen:

1. Ocultar tokens, `chat_id`, URLs privadas de Slack/Telegram, correos y
   cualquier dato sensible.
2. Usar nombres descriptivos, por ejemplo `evidencia-telegram-i4.png` o
   `F02-nodo-running.png`.
3. Referenciar la imagen desde el `.md` correspondiente y, si aplica, desde la
   matriz del README.

Las capturas complementan la evidencia; no la reemplazan. Cada caso debe tener
también el comando y la salida real en `evidence/`.
